Upload satu file CSV atau Excel (.xlsx). Hanya sheet pertama yang akan dibaca. Format: kolom pertama SKU, kolom kedua Nama item, kolom berikutnya adalah nama store dengan qty target sebagai nilai sel (kosongkan jika SKU tersebut tidak dikirim ke store tersebut). Satu SKU dapat memiliki qty di lebih dari satu store.


Reset dokumen tertaut

Tindakan ini akan menghapus data master yang telah diupload beserta seluruh hasil scan dan handling unit, sehingga anda dapat memulai kembali dengan file yang baru.

Apakah anda yakin?

Tindakan ini akan menghapus secara permanen data master yang telah diupload, seluruh scan, dan seluruh handling unit. Tindakan ini tidak dapat dibatalkan.

File berbeda terdeteksi

Mengupload file ini akan mereset seluruh data scan dan handling unit, karena nama file tidak sama dengan file yang terakhir diupload. Data master akan tetap diganti pada kedua kondisi, namun tindakan ini juga menghapus progress yang sudah berjalan.

Tentukan Prioritas Store

Urutan di bawah ini akan menjadi prioritas pengisian qty untuk setiap SKU (store paling atas diisi lebih dulu). Gunakan tombol panah untuk mengubah urutan jika diperlukan, lalu klik OK untuk melanjutkan.
